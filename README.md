# Menopausa Não Tem Cor

Site oficial do podcast **Menopausa Não Tem Cor**, desenvolvido em Next.js e pronto para publicação na Vercel.

## Publicação

1. Envie todos os arquivos deste projeto para um repositório no GitHub.
2. Na Vercel, escolha **Add New → Project** e importe o repositório.
3. Clique em **Deploy**.

A Vercel detecta o Next.js automaticamente. O projeto não exige variáveis de ambiente, banco de dados ou configuração adicional.

## Desenvolvimento local

```bash
pnpm install
pnpm dev
```

## Build de produção

```bash
pnpm build
```

Os episódios estão organizados em `app/episodios/page.tsx`. Quando os áudios e links oficiais estiverem disponíveis, eles poderão ser conectados ao player, aos downloads, ao YouTube e ao Spotify.
